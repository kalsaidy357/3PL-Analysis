# 3PL.Analytics — Delivery Performance & SLA Monitoring

A data-driven logistics analytics project that combines **Power BI and DAX** to transform delivery data into actionable insights for better SLA compliance and cost control.

---

## Project Objective

Monitor and analyze key delivery performance indicators such as **SLA breach rate, delay severity, courier performance, and regional trends**, helping identify where delivery performance breaks down and quantify its cost impact.

---

## Data Workflow

**Delivery Records → Power Query → Power BI → DAX & KPIs → Interactive Dashboard → Insights & Recommendations**

---

## Dashboard

### 3PL.Analytics

The dashboard provides a comprehensive view of:

- SLA Breach Rate
- First Attempt %
- Delay Severity
- Courier Performance
- Regional Performance
- Cost Impact

| Technology | Purpose |

---

## Key Outcomes

The project transforms raw delivery records into:

- Visual insights
- Performance KPIs
- SLA breach alerts
- Cost-linked performance tracking
- Operational decision-support insights

Analysis showed an **SLA breach rate of 18.0%** against a **10% target**, driven mainly by courier and regional variance, costing the business approximately **$100K in FY2025**.

---

## Business & Financial Analysis

The project also evaluated:

- On-time cost vs. breach cost
- Courier-level cost impact
- Potential savings from achieving the SLA target

This demonstrates how **data analytics can create direct financial value** by connecting operational performance with business costs.
